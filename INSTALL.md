# Farouq GitHub profile — Cyber Ops Motion Edition

## How to install

1. Open `https://github.com/farouqshaheen/farouqshaheen`.
2. Upload all FOUR SVG files from the `assets` folder, preserving `assets/` as the directory.
3. Replace the repository `README.md` with this updated README.
4. Ensure `farouq-header-onyx.png` remains at the repository root. You don't have to re-upload if it is already there.
5. Commit and refresh `https://github.com/farouqshaheen`.

## Animation / GitHub compatibility

The character movement, shot pulses, and status indicators use SMIL animations inside SVG images.
GitHub README does not execute arbitrary JavaScript. These files are self-contained.
If motion is disabled by the viewer's browser or accessibility preferences, static artwork is still visible.

This dashboard is an illustration of authorized lab security testing, not a real network attack.
